# ns.grillcheeseai.com

The organization site of Grillcheese-AI on GitHub Pages, served at `https://ns.grillcheeseai.com/`.

It hosts nothing itself but this landing page. Each vocabulary is its own repository published with GitHub Pages,
and appears under this domain at `/<repository>/`:

- CheezML: `https://ns.grillcheeseai.com/cheezml/` (repository Grillcheese-AI/cheezml), identified as
  `https://w3id.org/cheezml/`.
